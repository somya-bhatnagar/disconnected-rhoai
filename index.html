New in RHOAI 3.4

Product changes

Custom resources

MaaSModelRef, MaaSAuthPolicy, and MaaSSubscription replace the deprecated MaaSModel CR.

API key endpoint

Moved to /maas-api/v1/api-keys (was /v1/tokens). Keys use the sk-oai-* prefix.

Gateway service rename

maas-default-gateway-data-science-gateway-class replaces maas-default-gateway-openshift-default.

AuthConfig metadata

Now added automatically by the MaaSAuthPolicy controller — no longer a manual workaround.

Eight required workarounds

Disconnected cluster
  1. Gateway proxy routeFixes AddressNotAssigned on disconnected clusters
  2. WasmPlugin bastion authPull secret for bastion registry; non-persistent
  3. Authorino TLS trustService CA bundle so Authorino trusts MaaS API TLS
  4. NetworkPolicyAllow Gateway pods to reach maas-api
  5. PostgreSQL imagePoint postgres at the bastion registry digest
  6. Model endpoint overrideHTTP-only backend URL on MaaSModelRef
  7. HTTPRoute URL rewriteReplacePrefixMatch / if 3.4 did not add it
  8. Custom HTTP serverWhen llm-d-inference-sim is not mirrored

Workarounds 1–4

Infrastructure

1. Gateway proxy route Mandatory

OpenShift Route in openshift-ingress targeting maas-default-gateway-data-science-gateway-class on host maas.${CLUSTER_DOMAIN}, TLS edge.

2. WasmPlugin pull secret Mandatory

Copy cluster pull-secret into openshift-ingress as bastion-pull-secret, scale RHCL operator down, patch WasmPlugin imagePullSecret, scale back up. Re-apply if Gateway pods restart.

3. Authorino TLS trust Mandatory

Inject Service CA ConfigMap in kuadrant-system, mount it on the Authorino CR, set SSL_CERT_FILE=/etc/pki/service-ca/service-ca.crt.

4. NetworkPolicy Mandatory

Patch maas-authorino-allow in redhat-ods-applications so openshift-ingress Gateway pods can reach maas-api.

Workarounds 5–8

Data plane

5. PostgreSQL bastion image Mandatory

Prefer ./scripts/setup-database.sh with the bastion postgresql-16 digest. If already deployed, patch the postgres deployment image in redhat-ods-applications.

6. Model endpoint override HTTP backends

Set spec.endpointOverride on MaaSModelRef to the in-cluster HTTP service (simulator or custom server on port 8000).

7. HTTPRoute URL rewrite Verify in 3.4

Confirm a URLRewrite / ReplacePrefixMatch: / filter exists. Patch the model HTTPRoute if it is missing.

8. Custom HTTP server If sim image missing

ConfigMap Python OpenAI stub + Deployment using the bastion PostgreSQL image (has Python 3). Point MaaSModelRef and HTTPRoute at that Service; set LLMInferenceService replicas to 0.
