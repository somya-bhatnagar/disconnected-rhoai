Installation

Three steps

1. Deploy RHOAI from FBC fragment

Jenkins disconnected-setup mirrors the FBC GA fragment and installs from rhoai-catalog-base on channel stable-3.x (CSV 3.6.0).

2. Patch DSC

Default DSC ships with aigateway Removed. Set MaaS Managed and wait for ai-gateway-operator, maas-controller, and maas-api. KServe may stay Managed if mirrored.

3. MaaSAuthPolicy + MaaSSubscription

maas-gateway-auth is created only after the first MaaSAuthPolicy exists. Apply both CRs in models-as-a-service, then wait until the AuthPolicy is Enforced.

Workarounds 1–4

Infrastructure

1. Gateway proxy route Mandatory

Route maas-gateway in openshift-ingress to maas-default-gateway-openshift-default, host maas.${CLUSTER_DOMAIN}, TLS edge + redirect.

2. Authorino gRPC TLS Mandatory

RHCL 1.4.2 enables Authorino listener TLS but Envoy’s kuadrant-auth-service cluster has no transport_socket. Disable listener TLS or auth fails silently.

3. Service CA bundle Mandatory

Inject service-ca-bundle in kuadrant-system, mount it, set SSL_CERT_FILE and REQUESTS_CA_BUNDLE on Authorino.

4. Gateway memory 2Gi Recommended

WASM shim plus VM overhead exceeds the 1Gi default under policy reloads. Patch maas-default-gateway-config (also set WASM_INSECURE_REGISTRIES to bastion).

Workarounds 5–7

Custom HTTP backend

5. Custom HTTP server If sim image missing

Python OpenAI stub in a ConfigMap, deployed with the bastion PostgreSQL image. ExternalProvider + ExternalModel + MaaSModelRef with endpointOverride on port 8000. Service name: sim-http-backend.

6. Backend Service port map Mandatory for HTTP stub

In 3.6 the operator reconciles HTTPRoute to provider-sim-provider:443. Expose facebook-opt-125m-simulated Service with port 443 → 8000, DestinationRule TLS DISABLE, and ipp-managed secret label. HTTPRoute manual patch reverts quickly.

7. Secret label Mandatory

Label sim-provider-key with inference.llm-d.ai/ipp-managed=true. Without it, payload-processing ignores the secret and inference fails with authType 'apikey' credentials not found.
